# \# AMGE — Aplicativo Móvel para Gestão de Eventos

# 

# \## 1. Apresentação

# 

# O AMGE é um aplicativo móvel desenvolvido para facilitar o acesso dos participantes às informações e aos serviços de eventos de médio e grande porte.

# 

# \## 2. Objetivo

# 

# Centralizar os principais recursos relacionados à participação em eventos, proporcionando uma experiência intuitiva, organizada e eficiente.

# 

# \## 3. Funcionalidades previstas

# 

# \- Check-in por QR Code.

# \- Agenda personalizada.

# \- Mapa interativo do evento.

# \- Avaliações e feedback.

# \- Notificações aos participantes.

# 

# \## 4. Gerenciamento de Configuração

# 

# Este projeto utiliza Git e GitHub para controlar as versões dos artefatos, registrar modificações e manter os documentos disponíveis para os integrantes da equipe.
