

\# Requisitos Funcionais — AMGE



\## 1. Objetivo



Documentar os requisitos funcionais previstos para o aplicativo móvel de Gestão de Eventos (AMGE).



\## 2. Requisitos Funcionais



| ID | Requisito | Descrição |

|---|---|---|

| RF01 | Check-in por QR Code | Permitir que o participante realize o credenciamento por meio da leitura de um QR Code. |

| RF02 | Agenda personalizada | Permitir a consulta da programação e das atividades do evento. |

| RF03 | Mapa interativo | Disponibilizar um mapa para localização dos espaços e atividades do evento. |

| RF04 | Avaliações e feedback | Permitir que os participantes registrem avaliações sobre o evento. |

| RF05 | Notificações | Enviar notificações relevantes aos participantes. |



\## 3. Considerações



Os requisitos apresentados representam as funcionalidades previstas para o MVP do projeto AMGE e poderão ser atualizados conforme as solicitações dos stakeholders.
